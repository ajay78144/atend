📖 Beginner API Route Reference

Frontend (React, React Native, Axios, Fetch) me yeh direct URLs use karein:

Method Endpoint URL Purpose (Kaam) Required Fields
POST /api/employees Naya Employee register karna employeeId, name
GET /api/employees Sabhi employees ki list dekhna None
POST /api/attendance Daily Attendance mark karna (Present/Absent) employeeId, date, status
GET /api/attendance/date/:date Kisi date ki summary & present list nikalna :date (e.g. 2026-10-27)
GET /api/attendance/employee/:id Employee ki total percentage aur history :employeeId
PUT /api/attendance/update/:id/:date Galat lag gayi to attendance sudharna status
DELETE /api/attendance/delete/:id/:date Attendance record delete karna None
